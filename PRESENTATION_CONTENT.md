# Slide 1 — Problem & Objective

## Business Problem

New employees frequently need quick answers about:

- onboarding procedures
- security policies
- technical support
- company products

However, an onboarding assistant must not invent company policies or execute sensitive actions without authorization.

## Objective

Build a safe AI onboarding assistant that:

- uses only four approved documents
- retrieves relevant information
- provides citations
- abstains when information is unavailable
- supports account-access requests
- requires human approval before actions
- provides a visible workflow trace

## Key Principle

```text
Answer only from approved knowledge.
Act only after explicit approval.
